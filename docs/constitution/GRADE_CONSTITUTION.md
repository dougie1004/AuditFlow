# Grade Constitution v1.1 – AuditFlow

## Section 1. Constitutional Purpose

The AuditFlow Grade system is established to classify risk signals into discrete, state-bound categories. This Constitution exists specifically to **limit the scope of autonomous decision-making** and prevent the system from overreaching in its adjudication. 

In accordance with the "Phase 4 Entry Gate – AuditFlow" document, this system prioritizes **determinism, restraint, and responsibility**. Grades do not represent a fluid score of "badness"; they represent a formal procedural state that dictates the necessary level of human intervention. The primary goal is to ensure that every high-impact judgment (Grade A or Grade D) is derived from multiple, cross-verified dimensions of evidence.

---

## Section 2. Rule Taxonomy (NORMATIVE)

The system recognizes three, and only three, categories of rules. Each rule must be formally registered into one of these categories during implementation.

1.  **Intent-Strong Rules (IS)**:  
    Rules that identify structural patterns suggesting deliberate circumvention, concealment, or malicious intent (e.g., "Structuring/splitting payments to bypass approval limits").
2.  **Objective Violation Rules (OV)**:  
    Rules that identify clear, binary, and externally verifiable breaches of explicit policy (e.g., "Usage of corporate funds at a restricted merchant category code").
3.  **Contextual / Weak Signal Rules (CW)**:  
    Rules that identify statistical anomalies, heuristic outliers, or atmospheric risk markers (e.g., "Transaction occurred at 3 AM" or "High Anomaly Score").

**Operational Constraints:**
- **CW rules** are purely auxiliary; they MUST NOT trigger Grade A or Grade D status under any circumstances.
- An **IS rule** or an **OV rule** matched in isolation is INSUFFICIENT to establish a Grade A state.

## Section 3. Grade Semantics

| Grade | Legal Meaning | Automation Permission | Human Judgment Requirement |
| :--- | :--- | :--- | :--- |
| **Grade A** | **Confirmed Violation**: Intersection of intent and factual breach. | **ALLOWED** | None (Post-audit logs only) |
| **Grade B** | **Probable Irregularity**: High-suspicion pattern requiring justification. | **FORBIDDEN** | **MANDATORY** (Detailed Review) |
| **Grade C** | **Unresolved Anomaly**: Decision to withhold judgment due to uncertainty. | **FORBIDDEN** | **MANDATORY** (Formal Investigation) |
| **Grade D** | **Clean State**: Verified compliance within noise margins. | **ALLOWED** | None (Silent archival) |

## Section 4. Grade Assignment Constitution (CORE LAW)

The assignment of a Grade is a deterministic logic operation based solely on the combination of satisfied rules.

### 4.1 Grade A (Automatic Confirmation)
- **CONDITION**: Assigned ONLY IF (at least one **IS rule** is satisfied) AND (at least one **OV rule** is satisfied).
- **RATIONALE**: Both the "Intent" (logic of circumvention) and the "Body" (the factual violation) must be present to bypass human review.

### 4.2 Grade D (Automatic Dismissal) — REVISED
- **CONDITION**: Grade D is assigned ONLY IF ALL of the following conditions are met:
    1. Zero Intent-Strong Rules (IS = 0)
    2. Zero Objective Violation Rules (OV = 0)
    3. Contextual / Weak Signal Rules (CW) do not exceed a conservative noise threshold, such that no reasonable suspicion remains requiring human attention.
- **RATIONALE**: Automatic dismissal is constitutionally permitted only for signals that are demonstrably benign, not merely absent of explicit intent or policy breach. Any accumulation of contextual anomalies beyond background noise invalidates automatic dismissal and requires escalation to human judgment (Grade C).

### 4.3 Grade B and C (Human Mandatory) — REVISED
#### Grade B — Probable Irregularity
Assigned when:
- At least one primary rule (Intent-Strong OR Objective Violation) is satisfied, AND
- Contextual / Weak Signals materially strengthen suspicion, yet the constitutional intersection required for Grade A is incomplete.
- *Meaning*: Grade B represents cases where the system believes a violation is plausible, but constitutionally refuses to finalize judgment without expert justification.

#### Grade C — Unresolved Anomaly
Assigned when:
- Uncertainty dominates the signal evaluation, OR
- Only contextual / weak signals are present, OR
- The evidence is insufficient to justify Grade B escalation.
- *Meaning*: Grade C explicitly represents the system’s decision to withhold judgment, prioritizing false-positive avoidance over premature classification.

### 4.4 Explicit Prohibitions
1.  **Mono-Causal Adjudication**: A single rule match (IS, OV, or CW) MUST NOT result in Grade A.
2.  **Anomaly Supremacy**: An "Anomaly Score" is categorized as a CW rule. It MUST NOT independently assign any Grade.
3.  **Narrative Influence**: Text generated by AI witnesses is metadata only. It MUST NOT have any weight in the deterministic Grade assignment.

### 4.5 Clarifying Clause — CW Quantification Limitation
The Constitution deliberately refrains from specifying numeric thresholds for Contextual / Weak Signal accumulation. Any numeric interpretation (e.g., counts, scores, weights) MUST be defined in subordinate rule documentation, not in this Constitution, to preserve normative supremacy and future-proof governance.

## Section 5. Rust Pseudocode (ILLUSTRATIVE)

```rust
#[derive(PartialEq)]
pub enum RuleCategory { IntentStrong, ObjectiveViolation, WeakSignal }

pub enum Grade { A, B, C, D }

/// Pure function for deterministic grade assignment
/// No side effects, no AI input, no probabilistic logic.
pub fn assign_grade(triggered_rules: Vec<RuleCategory>, anomaly_score: f64) -> Grade {
    // NOTE: CW evaluation thresholds are illustrative only.
    // Constitutional logic defines states, not numeric tuning parameters.

    let is_count = triggered_rules.iter().filter(|&&cat| cat == RuleCategory::IntentStrong).count();
    let ov_count = triggered_rules.iter().filter(|&&cat| cat == RuleCategory::ObjectiveViolation).count();
    let cw_count = triggered_rules.iter().filter(|&&cat| cat == RuleCategory::WeakSignal).count();

    // 1. Grade A: Requires Intersection
    if is_count >= 1 && ov_count >= 1 {
        return Grade::A;
    }

    // 2. Grade D: Requires Zero Primary Triggers AND below noise threshold
    if is_count == 0 && ov_count == 0 && cw_count < 2 {
        return Grade::D;
    }

    // 3. Grade B: Partial Confirmation with Material Context
    if (is_count >= 1 || ov_count >= 1) && cw_count >= 2 {
        return Grade::B;
    }

    // Fallback: Uncertainty results in Grade C (Human investigation)
    Grade::C
}
```

Any implementation that automatically assigns Grade D in the presence of unresolved contextual anomalies SHALL be considered constitutionally invalid.
2.  **Immutability**: This Constitution may not be modified by data-driven tuning, model feedback, or threshold optimization. Any changes to the Grade logic require a formal human-led drafting of a subsequent version.
3.  **AI Exclusion**: No AI agent or probabilistic model has the authority to interpret or override the logic defined herein.
